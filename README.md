# NEON VOID v7.3 — آرنا سروایور نئونی (زرادخانه)

بازی Arena Survival کامل با **انجین اختصاصی Canvas 2D**: فیزیک، ۱۴ هوش مصنوعی دشمن با هویت بصری،
**۳ باس متفاوت** (اورلرد/جاگرنات/تمپست)، الیت‌ها با ۴ affix، موتاتور موج‌ها، ۸ پاورآپ، تیغه‌های مداری،
موشک‌های جوینده، انفجار نووا، **صاعقه زنجیره‌ای**، **شیرجه فاز**، سیستم ذرات پول‌شده،
موزیک تطبیقی سنتزشده (کمپرسور + داک + درام + شدت)، ۲۹ ارتقای روگ‌لایت + ری‌رول + اسکیپ،
دوربین lookahead، جم‌های رده‌بندی‌شده، کمبو با جایزه، دش گوستی، مینی‌مپ زنده، ۵ کشتی،
**آزمایشگاه متا (ارتقای دائمی)**، **پیروزی در موج ۲۰ + حالت بی‌پایان ♾️ + چک‌پوینت**،
گرید S/A/B/C، لیدربورد + تاریخچه ران محلی و ۲۰ اچیومنت پاداش‌دار.

> React 19 + TypeScript + Tailwind v4 + Vite + Canvas 2D + WebAudio ·
> بازی زنده: https://mahdyaralipor.github.io/neon-void/

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # بیلد production
npm run preview  # پیش‌نمایش بیلد
```

## گیم‌پلی v7.3 (زرادخانه)

- **هدف:** فتح موج ۲۰ = پیروزی (گرید S، ‎+۲۵۰۰ امتیاز، +۱۰◇) با سینماتیک آتش‌بازی؛ بعدش **حالت بی‌پایان ♾️** با امتیاز ×۱.۵ و اسکیل صعودی. رکورد، لیدربورد و تاریخچه ران ثبت می‌شود.
- **دوربین زنده:** lookahead به سمت aim و سرعت + کیک دش — همیشه می‌بینی کجا می‌روی.
- **هویت دشمن‌ها:** چشم چaser، بال Weaver، لوله Shooter/Sniper، تیغه Lancer، صفحات Tank، ترک Splitter، قلب تپنده Hive، حلقه چرخان + خشم نارنجی باس، اسکواش ضربه برای همه.
- **جم‌های رده‌بندی‌شده:** سبز/آبی/طلایی بر اساس ارزش + هاله طلایی جم‌های درشت.
- **اسکیپ ارتقا:** رد کردن = +۲۰ جان (کلید `0`)؛ هر لول همچنان ۱ ری‌رول دارد.
- **HUD:** شمارش kills-left زیر نوار موج؛ DPS صادقانه در پاز (مولتی‌شات + کریت).
- **روایت مرگ:** صفحه پایان قاتل را نشان می‌دهد («قاتل: اسنایپر»).
- **صدا:** کمپرسور باس برای میکس تمیز، داک موزیک روی نیوک/باس/پیروزی، throttle صدای درد.
- **آموزش:** سه راهنمای آرام برای اولین ران (۱۲ ثانیه اول).
- **آزمایشگاه:** نمایش بونس مجموع هر مسیر (+٪).

- **موزیک تطبیقی:** بیس + آرپ + کیک/هت/اسنیر — شدت با موج، شلوغی و باس بالا می‌رود؛ heartbeat کم‌جانی، کامبوتیک، throttle شلیک.
- **ری‌رول ارتقا:** هر لول‌آپ ۱ ری‌رول + نمایش استک (Lv x/y) و شمار بیلد فعال.
- **الیت‌های جدید:** بولوارک (تانک نارنجی، ۱.۵× امتیاز) و اکو (جم دوبرابر، حلقه فیروزه‌ای) + volatile/swift.
- **پاداش اچیومنت:** هر اچیومنت +۳◇ خرده خلأ؛ پاکسازی موج = وکیوم جم (۱.۶s مگنت).
- **ریتم تندتر:** اسپاون متراکم از موج ۳ (بچ ۲تایی/۳تایی)، کپ ۱۵۰، pity پاورآپ هر ۵۰s، Second Wind دواستکه (۶۰s + ۴۵٪ جان).
- **سلاح‌ها:** نووا قوی‌تر (pierce ۲، دمیج ۱.۲۵+)، سیکر ۳+ والی دوقلو، باف ارتقاهای ضعیف (pierce/velocity/magnet/xp...).
- **UI:** آمار زنده در پاز (دمیج/DPS/بیلد)، نوار پیشرفت موج، ت Hass اعداد دمیج، دکمه اشتراک نتیجه، رنگ واردن.
- **سرعت بازی:** آرام (0.9×) / استاندارد (1×) / توربو (1.۲۵×) — کل شبیه‌سازی تندتر، بالانس نسبی حفظ می‌شود.
- **کشتی‌ها:** ونگارد (متعادل)، فانتوم (سریع/شکننده/کریت)، تایتان (تانک/آرمور)، واردن (شروع با تیغه مداری)، **نومد** (مگنت و تجربه بیشتر، دمیج کمتر).
- **آزمایشگاه خلأ:** خرده‌های خلأ (◇) از الیت‌ها و باس‌ها → ۴ مسیر ارتقای دائمی (سلاح/بدنه/موتور/حافظه).
- **موج‌ها:** سهمیه کیل `6 + wave*4.5`؛ استراحت ۳.۲s + ۱۲٪ درمان؛ پورتال اسپاون با هشدار برای همه دشمنان.
- **موتاتورها (هر موج ۳م غیرباس):** هجوم گروهی، لانه اسنایپر، شکار الیت، موج سرعت، تب طلا (الیت و جم بیشتر)، طوفان خلأ (صاعقه تلگراف‌دار ×۱.۶)، **جنون** (اسپاون تندتر ×۱.۴ امتیاز).
- **۱۲ دشمن + ۳ باس:** Chaser، Weaver، Dasher، Shooter، Splitter، Mini، Sniper، Tank، Lancer (شارژ دوربرد با تلگراف)، Hive (زاینده مینی)، Stinger (استرِیف سریع + ۳تیر)، **Bomber** (سوت انفجار — دور شو!)، **Tesla** (برجک برق با خط تلگراف)، و **باس هر ۵ موج**: موج ۵ اورلرد (اسپیرال + احضار)، موج ۱۰ **جاگرنات** (شارژ + موج آتش)، موج ۱۵ **تمپست** (رگبار + صاعقه)، فینال موج ۲۰ — بی‌پایان چرخه را ادامه می‌دهد.
- **الیت‌ها (طلایی):** ۳.۲× جان، ۵× تجربه + affix + حلقه هشدار برای منفجرشونده‌ها.
- **۸ پاورآپ:** سپر، مگنت، نیوک، اور‌درایو، درمان، یخبندان (کند کردن زمان دشمنان)، **طمع** (جم ۲× برای ۲۰ ثانیه)، **فاز** (۵ ثانیه نامرئی + سرعت).
- **سلاح‌های جدید:** انفجار نووا (دوره‌ای)، موشک جوینده (هدایت‌شونده)، فرصت دوباره (نجات از مرگ)، **طوفان زنجیره‌ای** (صاعقه چندهدفه)، **شیرجه فاز** (دش دمیج‌زن)، **شکارچی سر** (کریت سنگین).
- **معامله‌ها:** **گلوله تک‌تیرانداز** (+۳۵٪ دمیج، -۱۰٪ فایر) و **دژ متحرک** (+۴۰ جان و آرمور، کندتر).
- **۲۰ اچیومنت ماندگار** + گرید S/A/B/C/D، top-5 و ۱۰ ران آخر محلی.
- **جهنمی واقعی:** درجه insane حالا جان/دمیج/سرعت بیشتر، اسپاون متراکم‌تر، الیت بیشتر و گلوله ۱۲٪ سریع‌تر — با +۲۵٪ امتیاز (سخت +۱۰٪).

## سرعت

- اسپрайت‌های glow از پیش پخته‌شده — صفر `shadowBlur` در حلقه داغ (بنر موج روی مد ضعیف با دابل‌دراو)
- spatial grid برای کالیشن‌ها، پولینگ گلوله‌ها، freelist ذرات، صفر allocation در هر فریم
- جم‌ها با یک drawImage (بدون save/rotate)، مینی‌مپ prop-driven با DPR
- کیفیت ۴سطحی خودکار (سینمایی/متعادل/عملکرد/سبک: FPS → ذرات/DPR/کپ دشمن) + بج FPS و auto-pause روی blur و مخفی شدن تب
- LOD رندر: نبولا/گلو/وینیت پله‌ای، جداسازی تناوبی، ریتارگت هومینگ هر ۳ فریم، مرج جم
